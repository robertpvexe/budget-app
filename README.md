# Budget App 💰

Prosta aplikacja do zarządzania budżetem miesięcznym.

## 🔧 Technologie
- .NET / ASP.NET Core Web API
- C#
- (opcjonalnie frontend jeśli masz)

## 📂 Struktura projektu
- `MonthlyBudget.Api` – backend API
- `MonthlyBudget.Web` – frontend (jeśli używasz)

## 🚀 Jak uruchomić

1. Otwórz solution:
New project.sln


2. Uruchom API:
dotnet run --project MonthlyBudget.Api


3. (opcjonalnie) uruchom frontend

## 📌 Funkcjonalności
- Dodawanie wydatków
- Usuwanie wydatków
- Przegląd budżetu miesięcznego
